# Деловые знакомства · СберБизнес (MVP, демо-версия)

Адаптивное mobile-first веб-приложение для делового нетворкинга между клиентами
СберБизнеса. Пользователь описывает, кого ищет; ИИ разбирает запрос, подбирает
кандидатов с оценкой совместимости и обоснованием; при взаимном интересе
открывается чат.

**Все внешние интеграции имитированы.** Ни SberBusiness ID, ни GigaChat не
вызываются по сети: оба адаптера полностью локальные и повторяют контракт
боевых систем. Ключи, VPN и доступ в контур Сбера для запуска не нужны.

## Запуск

```bash
npm install
npm run dev
```

- Приложение: http://localhost:5173
- API: http://localhost:4000

Прод-сборка (сервер сам отдаёт собранный фронтенд на http://localhost:4000):

```bash
npm run build && npm start
```

Сброс демо-данных: `npm run seed:reset` или кнопка в настройках приложения.

## Как пройти сценарий

1. На экране входа нажмите «Войти через СберБизнес ID».
2. Откроется имитация экрана согласия провайдера — выберите любую из шести
   тестовых компаний. Пароль не запрашивается.
3. Профиль подтянется из «СберБизнес ID»; отредактируйте запрос — по нему идёт
   подбор.
4. В ленте — карточки кандидатов с процентом совместимости и обоснованием.
   Свайп вправо или «Интересно» — лайк, влево или «Пропустить» — скип.
5. Демо-профили отвечают взаимностью с вероятностью 45% (настраивается) и через
   несколько секунд пишут первыми — чат открывается сразу.
6. В настройках можно включить сбой GigaChat и посмотреть фолбэк-подбор,
   изменить задержку ответа ИИ и увидеть метрики MVP.

Чтобы проверить чат между двумя живыми пользователями, откройте второе окно в
приватном режиме и войдите под другой тестовой компанией.

## Что имитируется и как заменить на боевое

| Что | Где | Чем заменить |
| --- | --- | --- |
| SberBusiness ID (OAuth2/OIDC) | `server/src/sberid.js`, `server/src/routes/mock.js` | Реальные `authorize` / `token` / `userinfo` провайдера: меняются URL и секреты, шаги потока те же |
| GigaChat API | `server/src/gigachat.js` | `callModel()` → HTTP-запрос к GigaChat. Системный промпт и разбор JSON уже готовы |
| PostgreSQL + Redis | `server/src/db.js` | Весь доступ к данным идёт через функции этого файла — меняется только он |
| База клиентов | `server/src/seed.js` | 20 демо-профилей предпринимателей |

Поток авторизации в демо полностью соответствует боевому: state-параметр,
одноразовый код с временем жизни 5 минут, обмен кода на токен, проверка статуса
клиента по ИНН, обработка отказа в доступе и истёкшей сессии. Пароли не
принимаются и не хранятся — только подписанный сессионный токен (HMAC-SHA256).

## Структура

```
server/
  src/
    index.js        точка входа, Express + Socket.IO
    config.js       конфигурация, параметры имитации
    db.js           слой данных (JSON-файл вместо PostgreSQL)
    seed.js         демо-профили и справочники
    sberid.js       имитация SberBusiness ID + сессионные токены
    gigachat.js     имитация GigaChat + фолбэк-скоринг без ИИ
    matching.js     подбор: кэш → ИИ → фолбэк, приватность профиля
    ws.js           real-time: сообщения, прочтение, онлайн-статус, набор текста
    routes/         auth, profile, feed, matches, mock
client/
  src/
    pages/          login, callback, onboarding, feed, matches, chat, profile, settings
    components/     nav, avatar, candidate card, profile form
    styles.css      фирменная палитра, mobile-first
```

## API

| Метод | Путь | Назначение |
| --- | --- | --- |
| POST | `/api/auth/sberid/start` | Начало входа, адрес экрана провайдера |
| POST | `/api/auth/sberid/callback` | Обмен кода на сессию |
| GET | `/api/auth/me` | Текущий пользователь |
| GET/PUT | `/api/profile` | Чтение и обновление профиля |
| GET | `/api/feed` | Подбор кандидатов (`?refresh=1` — пересчёт) |
| POST | `/api/feed/decision` | Лайк или скип, создание мэтча |
| GET | `/api/matches` | Список мэтчей |
| GET | `/api/matches/:id` | Мэтч и история переписки |
| POST | `/api/matches/:id/messages` | Отправка сообщения (фолбэк для WebSocket) |
| POST | `/api/matches/:id/close` · `/block` · `/report` | Завершение, блокировка, жалоба |
| GET/PUT | `/api/mock/settings` | Параметры имитации и системный промпт |
| GET | `/api/mock/metrics` | Метрики MVP |
| POST | `/api/mock/reset` | Сброс демо-базы |

WebSocket-события: `message`, `message:read`, `typing`, `presence`, `match`.

## Соответствие ТЗ

Реализовано: вход только через СберБизнес ID, профиль с приватностью, текстовый
запрос, ИИ-подбор со скором 0–100 и обоснованием, ранжированная выдача,
кэширование с пересчётом при изменении профиля, фолбэк без ИИ, лайк/скип и
свайпы, взаимный мэтч с уведомлением, история решений, раздел мэтчей, чат 1:1 с
историей, статусом прочтения и онлайн-статусом, завершение и блокировка диалога,
жалоба модератору, фирменный стиль и mobile-first вёрстка, метрики MVP.

Вне MVP, как и в ТЗ: звонки, вложения, групповые чаты, монетизация, нативные
приложения, расширенная модерация.

## Что дополнить перед пилотом

- Шрифты SB Sans лицензионные, в репозиторий не включены: в CSS они стоят первыми
  в стеке с системным фолбэком. Положите файлы в `client/public/fonts` и добавьте
  `@font-face`.
- Экран согласия на обработку персональных данных (152-ФЗ) при первом входе.
- Реальные БД и хранилище аватаров (S3), контейнеризация под контур Сбера,
  аудит доступа и логирование по требованиям ИБ.
