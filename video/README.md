# Ролик «Сберконнект»

Промо-ролик о функционале приложения (1:32, 1920×1080): заставка, затем
непрерывная запись реального интерфейса в телефоне с подписями этапов,
озвучкой и фоновой музыкой, в конце финальный титр. Готовые файлы:

- `out/sberconnect.mp4` — ролик;
- `out/subtitles.srt` — субтитры;
- `VOICEOVER.md` — текст диктора с таймкодами.

## Как пересобрать

```bash
# в корне репозитория — приложение должно работать
npm run dev

# в папке video
npm install
npx playwright install chromium   # один раз
npm run all
```

`npm run all` выполняет по порядку:

1. `voice`: озвучка сцен → `public/voice/*.wav` и их длительности.
2. `record`: один непрерывный прогон сценария в браузере → `public/clips/demo.mp4`.
   Каждая сцена длится не меньше своей фразы, поэтому стоп-кадров при монтаже нет.
3. `timeline`: раскладка по времени → `src/manifest.json`, субтитры, `VOICEOVER.md`.
4. `music`: фоновая музыка под длину ролика → `public/music.wav`. Синтезируется кодом,
   так что лицензии не нужны; свой трек можно положить вместо неё тем же файлом.
   Под голосом музыка автоматически приглушается (`MUSIC` в `src/Video.jsx`).
5. `render`: итоговый `out/sberconnect.mp4`.

`npm run studio` открывает Remotion Studio с монтажной линейкой и живым превью.
Вертикальная версия для Reels и Shorts: `npm run render:vertical`.

Служебные пометки демо-стенда об имитации интеграций на время записи скрываются.
`record` сбрасывает демо-базу и на время прогона включает 100% ответных лайков
и короткие задержки имитации, а после прогона возвращает настройки. Чаты и записи
на встречи, сделанные вручную, при этом пропадут.

## Элементы в PNG

`npm run elements` (нужен интернет для шрифтов) складывает в `out/elements/` элементы ролика
для монтажа в стороннем редакторе: логотипы, фоны, кадры заставки и финала, рамку телефона
с прозрачным экраном, подписи сцен, плашку и полосу этапов. Элементы с прозрачным фоном
и в двойном разрешении, фоны и кадры — ровно 1920×1080 и 1080×1920. Внешний вид — в `elements.mjs`.

## Что где менять

| Что | Где |
| --- | --- |
| Текст диктора, заголовки и пункты сцен | `script.json` |
| Действия в приложении и паузы | `record.mjs`: блоки по сценам, начало каждой отмечает `await mark('<id>')` |
| Внешний вид ролика | `src/Video.jsx` |

Если действия сцены заканчиваются раньше фразы, `mark()` сам ждёт на последнем
экране. Чтобы подольше задержаться на нужном экране, используйте
`holdUntil(<секунд до конца фразы>)`, как на экране согласия СберБизнес ID.

## Голос

Текст читает нейросетевой голос Microsoft `ru-RU-SvetlanaNeural` через
[edge-tts](https://github.com/rany2/edge-tts). Он запускается через `uvx`,
ключи не нужны, но нужен интернет, и текст озвучки уходит в облачный сервис
Microsoft. Скорость и высота голоса настраиваются в `script.json → voice`
(`rate`, `pitch`). Чтобы работать офлайн, укажите `"engine": "say", "name": "Milena", "rate": 185`
для системного голоса macOS.

Громкость фраз выравнивается автоматически (loudnorm, −16 LUFS), тишина по краям
файлов срезается.

### Произношение

Если голос неправильно читает слово, добавьте его в `script.json → pronounce`:
слово из текста → как его произносить, например `"Сберконнект": "Сбер конэкт"`.
Словарь влияет только на озвучку: подписи, субтитры и `VOICEOVER.md` остаются
в обычном написании. После правки запустите `npm run all`.

Знаки ударения (апостроф после гласной превращается в U+0301) технически
поддерживаются, но нейроголос с ними теряет интонацию и звучит неестественно.
Если ударение спорное, надёжнее перефразировать предложение.

### Своя запись диктора

Положите файлы в `public/voice/<id сцены>.wav` и выполните
`node voice.mjs --keep && npm run record && npm run timeline && npm run music && npm run render`:
синтез пропустится, запись и монтаж подстроятся под длину ваших фраз.
